Consensus
Overview
Consensus is a web application designed to streamline group decision-making for planning trips and activities. It allows users to create groups, submit activities, and vote on the best options, ensuring a collaborative approach to organizing events.

Features
User Authentication: Secure login and registration system.
Group Management: Create and join groups for collaborative planning.
Trip Planning: Set dates and time slots for activities.
Activity Submission: Users can submit activities with details such as descriptions, images, and prices.
Voting System: Each user can vote once per time slot, enabling fair selection of activities.
Automatic Itinerary Selection: Automatically selects the itinerary based on user votes.
Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Java (using Servlets without a database)
Frameworks: Spring Boot (for backend services)
Version Control: Git, GitHub

Usage
Create an Account: Register for an account to start using the application.
Create or Join a Group: Start a new group or join an existing one.
Plan Your Trip: Set up your trip by selecting dates and time slots.
Submit Activities: Add activities for each time slot with relevant details.
Vote on Activities: Participate in voting to select preferred activities.
View Itinerary: Automatically generated itineraries based on votes.
